# AI Lab Programs & Scenario-Based Problems

Welcome to the **AI Scenario-Based Problems** repository! This project contains a collection of classical Artificial Intelligence algorithms and problem-solving approaches implemented in Python. These programs demonstrate fundamental AI concepts, including various search strategies, planning, logical reasoning, and probabilistic models.

## Repository Structure

Here is an overview of the AI problems and algorithms implemented in this repository:

### Search & Optimization Algorithms
* **`astarwaterjug.py`**: Solves the classic Water Jug problem using the **A* Search Algorithm**.
* **`tsphillclimbing.py`**: Solves the Travelling Salesman Problem (TSP) using the **Hill Climbing Algorithm** and local search heuristics. 

### Game Playing & Adversarial Search
* **`tictactoealphabeta.py`**: An unbeatable Tic-Tac-Toe AI implemented using the **Minimax Algorithm with Alpha-Beta Pruning**.
* **`eightqueensbacktracking.py`**: Solves the 8-Queens puzzle utilizing the **Backtracking** algorithm.
* **`sudoko.py`**: Solves Sudoku puzzles using constraint satisfaction and backtracking.

### Logic & Knowledge Representation
* **`firstorderlogic.py`**: Demonstrates facts and rule representation using **First-Order Logic (FOL)**.
* **`wumpuslogic.py`**: Implements logical inference for navigating and surviving the classic **Wumpus World**.

### Constraint Satisfaction
* **`cryptarithmetic.py`**: Solves cryptarithmetic puzzles (e.g., SEND + MORE = MONEY) using Constraint Satisfaction problem-solving patterns.
* **`map.py`**: Map coloring constraint satisfaction logic.

### Graphs & Puzzles
* **`missionariescannibalsbfs.py`** & **`missionariescannibalsdfs.py`**: Solves the Missionaries and Cannibals problem showcasing both **Breadth-First Search (BFS)** and **Depth-First Search (DFS)**.
* **`missionarybfs.py`**: An alternative BFS implementation of the Missionaries and Cannibals problem.

### AI Planning Systems
* **`blocksworldplanning.py`**: Uses goal-stack planning techniques to solve the **Blocks World** problem.
* **`monkeybananaplanning.py`**: Solves the Monkey and Banana problem using AI logic and deductive planning.

### Probabilistic Reasoning
* **`bayesiannetwork.py`**: Demonstrates the use of a **Bayesian Network** to calculate joint probability distributions.

## How to Run

1. Make sure you have **Python 3.x** installed on your system.
2. Clone this repository (or download the files).
3. Open a terminal and navigate to the project directory.
4. Run any scenario by executing the Python file directly. For example:
   ```bash
   python tsphillclimbing.py
   ```

*Note: All algorithms have been standardized—variables are named in a clean lowercase format and outputs have been refactored for simplicity and ease of understanding.*
